# Reglas Contables

Catalogo de reglas del dominio `accounting`, una por archivo, con su norma de respaldo.

Toda regla debe declarar: rule_id, norm_version_id, vigencia, jurisdiccion, tipo de entidad,
marco, condiciones, accion y cita completa. Ver NORMATIVE_ENGINE.md seccion 5.

> Vacio en FASE 0: no hay normas en nivel V1 todavia. Se puebla en FASE 1-2.
